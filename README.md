# Nightfall Storyline FREE

Nightfall Storyline is a Guild Wars bot that automates progression through the Nightfall campaign. The FREE edition includes 16 Nightfall campaign phases.

## Download

Download the ready-to-use package from the [latest GitHub Release](https://github.com/sneal4you/Nightfall-Storyline-Free/releases/latest):

[Download NightfallStoryline-FREE.zip](https://github.com/sneal4you/Nightfall-Storyline-Free/releases/latest/download/NightfallStoryline-FREE.zip)

Extract the ZIP file while keeping its folder structure, then run the included launcher.

## Get a FREE license

Join the [Nightfall Storyline Discord server](https://discord.gg/378MDSMdrF), get the **Tester** role, and use the `/license` command in the licenses channel. Your license will be sent to you by direct message. It is valid for one device and does not expire. Enter the license key when the bot prompts you.

## Get a FULL license

The FULL license is not available yet. More information will be posted here when it becomes available.

## Usage instructions

1. Configure your Guild Wars account in the included launcher.
2. Launch Guild Wars from the launcher, sign in, and create a Dervish character.
3. Close Guild Wars completely.
4. Launch the Nightfall Storyline bot.
5. Select the configured account in the bot and start!
